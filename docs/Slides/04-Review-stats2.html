Where we are

Parts I–II introduced probability, random variables, sampling, and estimators. Here we turn to statistical inference: how we use a sample to learn about unknown population parameters.

The emphasis is on the intuition behind likelihood, frequentist inference, and Bayesian inference. We study one unknown probability with a loan-default example, then apply the same logic to a linear regression.

What is inference?

Statistical inference: the goal

Suppose a probability model contains an unknown parameter \(\theta\). We observe a sample \[y=(y_1,\ldots,y_n)\] and want to learn about \(\theta\).

  • Estimation gives us plausible values for the unknown parameter.
  • Inference tells us how uncertain we should be about those values.

Two frameworks

Framework Main idea
Frequentist Treat the parameter as fixed but unknown and study how an estimator behaves across repeated samples
Bayesian Represent uncertainty about the parameter with a probability distribution and update it using the observed data

For likelihood-based methods, both approaches begin with the same ingredient: a probability model for the data.

From a model to a likelihood

A running example — loan defaults

A bank observes 50 comparable loans, of which 8 default. Let \[D_i=\begin{cases}1,& \text{loan }i\text{ defaults},\\ 0,&\text{otherwise.}\end{cases}\]

Assume each loan has the same unknown default probability \(p\): \[D_i\overset{iid}{\sim}\operatorname{Bernoulli}(p),\qquad p\in(0,1).\]

If \(k\) defaults occur among \(n\) independent loans, \[K=\sum_{i=1}^{n}D_i\sim\operatorname{Binomial}(n,p),\qquad n=50,\ k=8.\]

Constructing the likelihood

For any proposed \(p\), the probability of exactly \(k=8\) defaults is \[P(K=8\mid p)=\binom{50}{8}p^{8}(1-p)^{42}.\]

Once the data are observed, \(k=8\) is fixed. We now read this as a function of the unknown \(p\): \[L(p;k)=\binom{50}{8}p^{8}(1-p)^{42}\ \propto\ p^{8}(1-p)^{42}.\]

Terms not involving \(p\) do not change which value maximises it.

What the likelihood is — and is not

More generally, \[L(\theta;y)=f(y\mid\theta),\] with the observed data \(y\) held fixed and the likelihood viewed as a function of \(\theta\).

Important. A likelihood is not a probability distribution for the parameter. It need not integrate to one over \(\theta\). It measures the relative support the data give to different parameter values.

R — the likelihood for \(p\)

n <- 50
k <- 8

p_grid  <- seq(0.001, 0.40, length.out = 500)
log_lik <- dbinom(k, size = n, prob = p_grid, log = TRUE)

# Scale the likelihood so its maximum is 1
rel_lik <- exp(log_lik - max(log_lik))
p_hat   <- k / n

plot(p_grid, rel_lik, type = "l", lwd = 2,
     xlab = "Default probability p", ylab = "Relative likelihood",
     main = "Likelihood for p: 8 defaults in 50 loans")
abline(v = p_hat, lty = 2, lwd = 2)

The maximum-likelihood estimate

The likelihood peaks at \[\hat p=\frac{8}{50}=0.16.\]

This is the maximum-likelihood estimate (MLE).

The data give greatest support to a default probability of about 16%, though nearby values are also plausible. Inference asks how much uncertainty remains around this estimate.

Frequentist inference

Uncertainty through repeated sampling

In the frequentist framework \(p\) is a fixed but unknown constant. Before the sample is drawn the data are random, so the estimator \(\hat p=K/n\) is random too.

\[\text{model}\longrightarrow\text{estimator}\longrightarrow\text{sampling distribution}\longrightarrow\text{SE, CI, test}.\]

Three tools, three meanings

  • Standard error — the standard deviation of the estimator’s sampling distribution; how much the estimate would vary from sample to sample.
  • 95% confidence interval — a procedure such that, under repeated sampling, about 95% of the intervals it produces contain the true parameter. The 95% refers to the procedure, not to this one interval.
  • p-value — the probability, under the null model, of a test statistic at least as extreme as observed. It is not the probability that \(H_0\) is true.

For example, test \(H_0:p=0.10\).

R — frequentist inference for \(p\)

p_hat <- k / n

# Exact (Clopper-Pearson) test and interval
default_test <- binom.test(x = k, n = n, p = 0.10, conf.level = 0.95)

# Normal-approximation (Wald) SE and interval, for comparison
wald_se <- sqrt(p_hat * (1 - p_hat) / n)
wald_ci <- p_hat + c(-1, 1) * 1.96 * wald_se

cat("p_hat      =", round(p_hat, 4), "\n")
cat("Wald SE    =", round(wald_se, 4), "\n")
cat("Wald 95% CI=", round(wald_ci, 4), "\n\n")

default_test

Reading the result

  • Point estimate \(\hat p=0.16\).
  • The exact Clopper–Pearson interval \([0.072,\,0.291]\) is not symmetric around \(\hat p\) and differs slightly from the Wald interval \(\hat p\pm1.96\,\widehat{\mathrm{SE}}\); the two agree more closely as \(n\) grows.
  • The p-value (\(\approx 0.16\)) asks how unusual 8 defaults in 50 would be if \(p=0.10\). At the 5% level it does not reject \(H_0:p=0.10\).

How would our estimator behave if we repeatedly sampled loans from the same population?

Bayesian inference

Posterior \(\propto\) likelihood \(\times\) prior

Bayesian inference starts from the same likelihood but adds a prior for \(p\): \[\pi(p\mid y)=\frac{L(p;y)\,\pi(p)}{\int L(p;y)\,\pi(p)\,dp},\]

\[\boxed{\ \text{Posterior}\ \propto\ \text{Likelihood}\ \times\ \text{Prior}\ }\]

  • Prior \(\pi(p)\) — belief about \(p\) before the current data.
  • Likelihood \(L(p;y)\) — what the data say about different \(p\).
  • Posterior \(\pi(p\mid y)\) — belief about \(p\) after combining them.

A simple prior

Suppose past experience suggests default rates around 10%. For illustration take \[p\sim\operatorname{Beta}(2,18),\qquad E(p)=\frac{2}{2+18}=0.10.\]

The Beta distribution is convenient for probabilities because all of its mass lies between 0 and 1.

Conjugacy — Beta prior, Beta posterior

For a Binomial likelihood and a \(\operatorname{Beta}(a,b)\) prior, the posterior is again Beta: \[p\mid y\ \sim\ \operatorname{Beta}(a+k,\ b+n-k).\]

With \(a=2,\ b=18,\ k=8,\ n=50\): \[p\mid y\ \sim\ \operatorname{Beta}(10,60),\qquad E(p\mid y)=\frac{10}{70}\approx 0.143.\]

The sample alone suggests 16%; the prior was centred at 10%; the posterior combines both and lands between them.

R — Bayesian inference for \(p\)

a_prior <- 2; b_prior <- 18
a_post  <- a_prior + k
b_post  <- b_prior + n - k

posterior_mean    <- a_post / (a_post + b_post)
credible_interval <- qbeta(c(0.025, 0.975), a_post, b_post)
prob_above_10     <- 1 - pbeta(0.10, a_post, b_post)

round(c(posterior_mean       = posterior_mean,
        lower_95             = credible_interval[1],
        upper_95             = credible_interval[2],
        `P(p > 0.10 | data)` = prob_above_10), 4)

A stronger prior pulls the posterior toward the prior mean; more data (or the same \(k\) with the shape sharpened) lets the likelihood dominate.

Credible interval & direct probability

A 95% credible interval contains 95% of the posterior probability for \(p\), given model, prior, and data. Unlike a confidence interval, we can ask direct questions such as \(P(p>0.10\mid y)\).

Here \(P(p>0.10\mid y)\approx 0.85\), while the exact test does not reject \(H_0:p=0.10\) (p \(\approx 0.16\)). No conflict — they answer different questions. The test: how surprising 8/50 would be if \(p=0.10\). The posterior: how probable \(p>0.10\) is given the data and prior.

Same observed data and likelihood — different treatment of uncertainty.

From one parameter to regression

The wage–education question

The loan example has one unknown, \(p\). Econometric models usually have several. We ask:

How is hourly wage associated with years of education?

Using the wage1 dataset from the wooldridge package, let \[Y_i=\log(\text{hourly wage}_i),\qquad X_i=\text{years of education}_i,\] \[Y_i=\beta_0+\beta_1 X_i+\varepsilon_i.\]

This is an associational regression. By itself it does not establish that education has a causal effect on wages.

Building the regression likelihood

The equation specifies only the conditional mean: \[E(Y_i\mid X_i=x_i)=\beta_0+\beta_1 x_i.\]

For a likelihood we add a model for the disturbances. Assume \(\varepsilon_i\overset{iid}{\sim}N(0,\sigma^2)\), so \[Y_i\mid X_i=x_i\ \sim\ N(\beta_0+\beta_1 x_i,\ \sigma^2),\qquad \theta=(\beta_0,\beta_1,\sigma).\]

\[f(y_i\mid x_i,\theta)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\left[-\frac{(y_i-\beta_0-\beta_1 x_i)^2}{2\sigma^2}\right].\]

The log-likelihood

Assuming conditional independence, \[L(\theta;y,X)=\prod_{i=1}^{n} f(y_i\mid x_i,\theta),\]

\[\ell(\theta)=-\frac{n}{2}\log(2\pi)-n\log\sigma-\frac{1}{2\sigma^2}\sum_{i=1}^{n}(y_i-\beta_0-\beta_1 x_i)^2.\]

Why OLS appears

For a fixed \(\sigma\), maximising the Gaussian log-likelihood over \(\beta_0,\beta_1\) is the same as minimising \[\sum_{i=1}^{n}(y_i-\beta_0-\beta_1 x_i)^2.\]

Under normally distributed errors, the maximum-likelihood estimates of the regression coefficients are exactly the ordinary least-squares estimates.

R — maximise the likelihood directly

y <- wage1$lwage
x <- wage1$educ

neg_loglik <- function(par, y, x) {
  beta0 <- par[1]; beta1 <- par[2]
  sigma <- exp(par[3])           # log(sigma) keeps sigma > 0
  mu    <- beta0 + beta1 * x
  -sum(dnorm(y, mean = mu, sd = sigma, log = TRUE))
}

mle_fit <- optim(par = c(0, 0, log(sd(y))), fn = neg_loglik,
                 y = y, x = x, method = "BFGS", hessian = TRUE)

mle_estimates <- c(beta0 = mle_fit$par[1],
                   beta1 = mle_fit$par[2],
                   sigma = exp(mle_fit$par[3]))
round(mle_estimates, 4)

The optimiser searches over \((\beta_0,\beta_1,\sigma)\) for the values that make the observed wages most compatible with the Gaussian model.

R — MLE equals OLS

fit <- lm(lwage ~ educ, data = wage1)
coef(fit)

# Coefficients agree
rbind(MLE = mle_estimates[c("beta0", "beta1")],
      OLS = coef(fit))

# Standard errors also agree: MLE (inverted Hessian) vs OLS
mle_se <- sqrt(diag(solve(mle_fit$hessian)))[1:2]
se_tab <- rbind(`MLE SE` = unname(mle_se),
                `OLS SE` = unname(summary(fit)$coefficients[, "Std. Error"]))
colnames(se_tab) <- c("beta0", "beta1")
round(se_tab, 4)

Frequentist regression inference

Sampling distribution of the slope

\(\beta_1\) is a fixed but unknown parameter. The estimate \(\hat\beta_1\) comes from this sample; across repeated samples it would vary — its sampling distribution. From it we obtain:

  • a standard error for \(\hat\beta_1\);
  • a confidence interval for \(\beta_1\);
  • a test of, say, \(H_0:\beta_1=0\).

In a log-wage regression the slope is approximately the proportional difference in wage associated with one more year of education.

R — summary and interval

summary(fit)
confint(fit, "educ", level = 0.95)

Interpretation

\(\hat\beta_1\approx 0.083\), SE \(\approx 0.008\) (so \(t\approx 11\), p-value \(\approx 0\)), 95% CI \(\approx[0.068,\,0.098]\). One extra year of education is associated with about an 8% higher hourly wage on average (\(R^2\approx 0.19\), \(n=526\)).

The SE measures sampling uncertainty of the slope; the CI is read through repeated sampling; the p-value evaluates \(H_0:\beta_1=0\) under the model. Again — an association, not automatically a causal effect.

Bayesian regression inference

Same likelihood, add priors

The likelihood is unchanged: \[Y_i\mid X_i,\beta_0,\beta_1,\sigma^2\ \sim\ N(\beta_0+\beta_1 X_i,\ \sigma^2).\]

Add weak priors, e.g. \[\beta_0\sim N(0,10^2),\qquad \beta_1\sim N(0,1^2),\] \[p(\beta_0,\beta_1,\sigma^2\mid y,X)\ \propto\ L(\beta_0,\beta_1,\sigma^2;y,X)\,p(\beta_0,\beta_1,\sigma^2).\]

For realistic models the posterior is obtained numerically. We draw from it with MCMCregress(); the MCMC mechanics are not our focus — the draws let us summarise posterior uncertainty.

R — draw from the posterior

Interpreting the posterior

  • Posterior mean — a point summary of \(\beta_1\).
  • Posterior SD — the size of posterior uncertainty.
  • 95% credible interval — 95% of the posterior probability for \(\beta_1\).
  • \(P(\beta_1>0\mid y,X)\) — posterior probability the association is positive, given model and prior.

With a sizeable sample and weak priors, Bayesian and frequentist numbers are often similar; their interpretations stay different.

Where this leads

Likelihood dominates here

On wage1 both columns are almost identical — slope near 0.083, 95% interval \(\approx[0.068,\,0.098]\).

With 526 observations and weak priors the likelihood dominates, so the posterior sits essentially on top of the OLS estimate. The two would diverge with a small sample or a strong prior — exactly where Bayesian shrinkage becomes valuable, as in the VARs later in the course.

Recap

  • A likelihood measures the relative support the data give to parameter values — it is not itself a distribution over \(\theta\).
  • The MLE maximises it; under normal errors, MLE is OLS.
  • Frequentist inference reads uncertainty through the sampling distribution: SE, confidence interval, p-value.
  • Bayesian inference adds a prior and updates it: posterior mean, credible interval, direct probability statements.
  • Same data and likelihood — the frameworks differ in how they represent and interpret uncertainty.
